# KMX CSV再生 — RSR起動＋I/Oハンドシェイク セットアップ

「品種番号・パス番号をセット → DI ON で KMX_PLAY 起動 → 起動確認できたら DI OFF → 完了を待つ」を
FANUC の **RSR（Robot Service Request）** ＋ **DO ハンドシェイク**で実現する手順。ROBOGUIDE で検証 → 実機へ移植。

---

## 1. I/O ハンドシェイク定義（★I/O番号は例。実機I/Oマップに合わせて変更可）

| 信号 | 種別 | 例 | 向き | 意味 |
|---|---|---|---|---|
| 開始要求 | UOP RSR1 = **UI[9]** | UI[9] | PLC→ロボ | ON でKMX_PLAY起動要求（エッジ起動） |
| 品種番号 | レジスタ **R[89]** | — | PLC→ロボ | 起動前にセット |
| パス番号 | レジスタ **R[88]** | — | PLC→ロボ | 起動前にセット（0=復帰動作） |
| 実行中 | **DO[101]** | DO[101] | ロボ→PLC | KMX_PLAY走行中ON（＝起動確認） |
| 完了 | **DO[102]** | DO[102] | ロボ→PLC | 正常終了でON |
| 異常 | **DO[103]** | DO[103] | ロボ→PLC | 失敗でON（CSV無し/EOF/件数不正 R[96]=-1） |

### シーケンス
```
1. PLC: R[89]=品種, R[88]=パス をセット
2. PLC: UI[9](RSR1) = ON            → ロボ: RSR0001 起動 → CALL KMX_PLAY
3. ロボ: DO[101]=ON（実行中）       ← PLC: 起動確認
4. PLC: UI[9] = OFF                 （RSRはエッジ起動なのでOFFにして良い）
5. ロボ: KMX_LOAD→PR充填→100点再生
6. ロボ: DO[101]=OFF, DO[102]=ON（完了）  ← PLC: 完了検知
   （異常時）DO[101]=OFF, DO[103]=ON      ← PLC: 異常検知
```

---

## 2. ロードするファイル
| ファイル | 種別 | 備考 |
|---|---|---|
| `kmx_load.pc` | Karel PC | CSV→PR（品種+パス対応・SET_JPOS_REG版） |
| `KMX_PLAY.LS` | TP | DOハンドシェイク付き（実行中/完了/異常） |
| `RSR0001.LS` | TP | RSR1で起動される薄いラッパー（`CALL KMX_PLAY`） |

※ `KMX_PLAY.LS` は KMX_LOAD が存在する状態でロードすること（CALL結合のため）。

---

## 3. RSR 設定
1. `MENU` → `6 セットアップ` → `F1[タイプ]` → **プログラム選択**
2. **プログラム選択方式 = RSR** に設定 → 有効化
3. **RSR1 → プログラム番号 1**（＝ `RSR0001` が起動する。ベース名 RSR + 0001）
   - 「基準番号(base)」が 0 であることを確認（RSR1=RSR0001）

## 4. UOP（リモートI/O）前提 ★これが揃わないとRSR起動しない
- **AUTO モード** かつ **REMOTE**（LOCAL では不可）
  - `$RMT_MASTER = 0`（UOPをリモートマスタに）
- UOP 許可入力を全て ON：
  - **UI[1] \*IMSTP = ON**（非常停止でない）
  - **UI[2] \*HOLD = ON**（ホールドでない）
  - **UI[3] \*SFSPD = ON**（安全速度OK）
  - **UI[8] ENBL = ON**（動作許可）
  - ※ \* 付きは正論理の許可信号＝ONで正常
- UOP を物理I/O（ラック/スロット）へ割付、または ROBOGUIDE の I/O 画面で UI を操作

## 5. ROBOGUIDE でのテスト手順
1. 上記3ファイルをロード、RSR有効化（§3）、UOP前提を満たす（§4）
2. **R[89]=1, R[88]=1**（→ `UD1:\KMX\P1_1.CSV` を読む。復帰は R[88]=0 → `P1_0.CSV`）
3. AUTO+REMOTE、UI[1]/[2]/[3]/[8]=ON を確認
4. **UI[9](RSR1) を ON** → KMX_PLAY 起動、**DO[101]=ON** になるのを確認（起動確認）
5. **UI[9] を OFF** → そのまま再生継続
6. 100点再生完了で **DO[101]=OFF, DO[102]=ON**（完了）を確認
   - CSV が無い等なら **DO[103]=ON**（異常）

### ROBOGUIDE で UI/DO を見る/操作する
- `MENU` → `5 I/O` → `F1[タイプ]` → **UOP**（UI/UO）／**デジタル**（DI/DO）
- UI[9] を ON にするには、UOP入力を物理割付するか、I/O画面で強制（SIM/強制ON）

---

## 6. 注意
- **I/O番号（DO[101..103], UI[9]）は例**。実機I/Oマップに合わせて `KMX_PLAY.LS` の DO 番号・UOP割付を変更。
- RSR はエッジ起動＝UI[9] を ON にした瞬間に要求がラッチされる。手順4でONにした後、手順5でOFFにして良い（完了は DO で待つ）。
- **異常DO[103]** が出たら R[97]/R[98]/R[99]（診断）と USER 画面を確認（OPEN/READ/デバイス）。
- 実機移植：UOP割付・I/O番号を実機に合わせるだけ。プログラム（RSR0001/KMX_PLAY/kmx_load）は共通。

## 7. レジスタ／PR 規約（再掲）
- R[89]=品種, R[88]=パス番号(0=復帰), R[90..95]=count/group/uframe/utool/speed/cnt, R[96]=1成功/-1失敗, R[97..99]=診断
- PR[1..count] = 各点関節（SET_JPOS_REG）
